# Exported Poster Vector Figures

All SVG files in this folder use a consistent width of `1000`; heights vary by figure so shorter charts stay compact for poster/report layout. They are exported from `poster/export_vector_figures.py`.

The figures mirror the main generated charts/diagrams used in `poster/poster.tex`:

- `dataset_label_distribution.svg`
- `reference_length_mismatch.svg`
- `roc_auc_short_qa.svg`
- `roc_auc_nq_reference_extraction.svg`
- `roc_auc_combined_short_and_nq.svg`
- `failure_manual_categories.svg`
- `failure_errors_meaning.svg`
- `pipeline_overview.svg`
- `improvement_roadmap.svg`
